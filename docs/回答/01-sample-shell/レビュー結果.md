# HANDS-001 Step 07 レビュー結果

## コード確認

| 確認項目 | 結果 | 内容 |
|---|---|---|
| RouteとScreenの分離 | OK | RouteがNavigationと共通レイアウトを担当し、Screenは表示内容だけを受け取る |
| NavControllerの責務 | OK | NavControllerはGraphとRouteからのみ参照する |
| 共通Navigation部品 | OK | `SampleNavigationComponents.kt`は表示とクリック通知を担当し、遷移処理を持たない |
| Drawer表示中のBack | OK | `BackHandler`でDrawerを閉じる |
| Bottom Navigationの重複遷移 | OK | `launchSingleTop`と`popUpTo`で同一タブの重複を抑制する |
| 業務ロジックの混入 | OK | ViewModel、UseCase、Repository、DataStore、Roomはこの課題に追加していない |

## 手動確認項目

次の項目はエミュレーターまたは実機で確認する。

- 起動時にHome画面が表示される
- Home、履歴、設定をBottom Navigationで切り替えられる
- Home、履歴、設定から戻る操作を行える
- Drawerを開いてBackを押すとDrawerだけが閉じる
- Drawerからライセンスなどの画面へ遷移できる
- 遷移先からBackで直前の画面へ戻れる
- 同じBottom Navigation項目を連続して押しても画面が重複しない
- 小さい画面幅でもタイトル、Drawer、Bottom Navigationが欠けない

このレビューではコード確認とコンパイル確認を実施し、実機操作の結果は記録していない。
