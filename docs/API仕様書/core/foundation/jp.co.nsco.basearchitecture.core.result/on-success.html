onSuccess

inline fun <T> AppResult<T>.onSuccess(action: (T) -> Unit): AppResult<T>

成功時に副作用処理を実行する。

AppResult.Success の場合のみ action を実行し、 戻り値として元の AppResult をそのまま返す。

ログ出力、後続処理の呼び出し、状態更新前の補助処理など、 成功時だけ追加処理を行いたい場合に使用する。

■ 注意 action 内で発生した例外は捕捉しない。 本関数は値変換ではなく、副作用実行用の補助関数である。

Return

元の AppResult。

Parameters

action

成功時に実行する処理。
