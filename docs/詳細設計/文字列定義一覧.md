# BaseArchitecture 文字列定義一覧

## 1. 目的

本書は、`app/src/main/res/values/strings.xml` に定義された表示文言と利用目的を一覧化する。

UI文言はResourceで管理し、ViewModel、UseCase、DomainはAndroid Contextやresource IDを直接保持しない。PresentationのFormatter、Mapper、Factory、またはComposableの `stringResource` を介して解決する。

現行の英語文言は、Sampleの入力検証・エラー表示を中心に残っている。案件適用時は日本語・英語の文言方針を確定し、必要に応じてvalues-ja / values-enへ分離する。

## 9. 管理ルール

- Resource名は既存Featureのprefixを維持する。
- 表示文言をKotlinへ直書きしない。
- 文言変更時は本書と `strings.xml` の両方を更新する。
- Placeholder引数の型・順番を変更する場合は利用箇所とUnit Testを同時に確認する。
- 案件適用時はSample固有の文言を案件用Resourceへ置き換える。
