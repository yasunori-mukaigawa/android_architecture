# HANDS-002 レビュー確認項目

## Module境界

- [ ] `core:foundation`がAndroid UIやNavigationへ依存していない
- [ ] `core:presentation`がFoundationの契約を利用している
- [ ] Feature固有の型がCoreへ混入していない
- [ ] Coreへ業務固有の名前やSample固有の処理を追加していない

## Result / Error / Validation

- [ ] Kotlin標準`Result<T>`を使っていない
- [ ] 成功値と失敗理由を`AppResult`で表現している
- [ ] `AppError`と`UiError`を混同していない
- [ ] 入力項目の検証結果を`FieldValidationResult`で表現できる
- [ ] Errorの`code`と表示文言を直接結び付けていない

## Presentation契約

- [ ] `UiState`は再描画しても同じ意味になる状態だけを保持する
- [ ] `UiEvent`はViewからの入力として扱っている
- [ ] `UiMessage`はState更新理由として扱っている
- [ ] `UiEffect`はNavigation、Dialog、Snackbarなどの単発処理に限定している
- [ ] Reducerは純粋なState変換になっている

## BaseViewModel

- [ ] MutableStateFlowがBaseViewModel内に閉じている
- [ ] MutableSharedFlowがBaseViewModel内に閉じている
- [ ] UiEventをChannelへ積んでいる
- [ ] Channelのイベントを順番に`handleEvent`へ渡している
- [ ] `dispatch`がReducer経由でStateを更新している
- [ ] `emitEffect`がEffectだけを発行している
- [ ] LoadingやErrorの自動処理をBaseViewModelへ追加していない

## 比較

- [ ] SampleAppの対応ファイルを確認した
- [ ] コメント以外の実装差分を確認した
- [ ] 差分がある場合、対応表の後続Stepで解消する差分として記録した
