# Step 4: Bottom Navigation接続

## 目的

Sample Home / History / SettingsのRouteへBottom Navigationを接続する。

## SampleAppとの対応

- `SampleBottomNavigationItem`
- `SampleBottomNavigation`
- `SampleRoutes.List`
- `SampleRoutes.History`
- `SampleRoutes.Settings`
- 各Sample RouteのBottom Navigation接続

## 課題

- 現在のRouteから選択中のNavigation itemを決める
- item選択時に対応するRouteへ遷移する
- 同じRouteを重複してBack Stackへ積まない
- Home / History / Settingsのどの画面でも共通Bottom Navigationを表示する

## 制約

- ScreenにNavControllerを渡さない
- 選択状態を画面ごとに別管理しない
- Tab遷移処理をSampleNavigationComponentsへ書かない

## 完了条件

- [ ] 3画面間をBottom Navigationで遷移できる
- [ ] 現在Routeと選択中itemが一致する
- [ ] Homeが初期選択される
- [ ] 連続選択でRouteが重複しない
