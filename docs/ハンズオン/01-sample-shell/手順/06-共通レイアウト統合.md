# Step 6: 共通レイアウト統合

## 目的

Sample Home / History / Settingsの各Routeへ、Sample Feature共通の画面構造を組み込む。

## SampleAppとの対応

- `SampleRoute`
- `SampleHistoryRoute`
- `SampleSettingsRoute`
- `SampleTopBar`
- `SampleDrawerContent`
- `SampleBottomNavigation`

## 課題

各Routeを次の構造へ揃える。

```text
ModalNavigationDrawer
  └─ Scaffold
      ├─ SampleTopBar
      ├─ Screen content
      └─ SampleBottomNavigation
```

- RouteがNavigationとDrawer状態を接続する
- Screenへ表示値と操作callbackだけを渡す
- Placeholder画面を共通レイアウト内へ表示する
- 画面タイトルをRouteからResource経由で渡す

## 制約

- ScreenへNavControllerを渡さない
- ScreenへDrawerStateを渡さない
- Placeholder画面へ業務処理を追加しない
- 共通部品の見た目を各Screenで再実装しない

## 完了条件

- [ ] Home / History / Settingsの見た目が揃っている
- [ ] 共通TopAppBarが利用されている
- [ ] 共通Drawerが利用されている
- [ ] 共通Bottom Navigationが利用されている
- [ ] 各ScreenがNavigation実装を知らない
