# Step 5: Navigation Drawer接続

## 目的

Sample FeatureのDrawerから、Legal / License / VersionInfo Featureへ遷移できるようにする。

## SampleAppとの対応

- `SampleDrawerContent`
- `SampleDrawerItem`
- `LegalDocumentRoutes`
- `LicenseRoutes`
- `VersionInfoRoutes`
- `SampleRoute`のDrawer接続

## 課題

- Drawerを開くためのTopAppBar操作を接続する
- Drawer項目を表示する
- プライバシーポリシーと利用規約をLegal Routeへ接続する
- ライセンスをLicense Routeへ接続する
- バージョン情報をVersionInfo Routeへ接続する
- 遷移前にDrawerを閉じる

## 制約

- Legal / License / VersionInfoのRoute文字列をSample側へ複製しない
- Drawerの表示部品と遷移処理を分離する
- まだ文書本文、License一覧、Version取得処理は追加しない

## 完了条件

- [ ] Drawerを開閉できる
- [ ] 4項目が表示される
- [ ] 4項目から対応するPlaceholderへ遷移できる
- [ ] 遷移後にDrawerが閉じている
- [ ] Back操作でDrawerを閉じられる
