# Step 3: SampleNavigationComponents

## 目的

Sample Feature内で共有するTopAppBar、Drawer、Bottom NavigationのComposableを作る。

## SampleAppとの対応

- `feature/sample/presentation/common/SampleNavigationComponents.kt`
- `SampleTopBar`
- `SampleDrawerContent`
- `SampleBottomNavigation`
- `SampleBottomNavigationItem`
- `SampleDrawerItem`

## 課題

- TopAppBarに画面タイトルとメニューアイコンを表示する
- Drawerの表示項目をモデルまたは一覧定義へ集約する
- Bottom Navigation itemを定義する
- 各Composableはクリック通知をcallbackで受け取る
- Material3 ThemeとResourceを利用する

## 制約

- 共通Composable内でNavControllerを操作しない
- 共通Composable内でUseCaseやRepositoryを呼び出さない
- 共通Composable内へ画面遷移の副作用を直接書かない

## 完了条件

- [ ] 3つの共通Composableを個別にPreviewで確認できる
- [ ] Bottom Navigationの項目がHistory / Home / Settingsになっている
- [ ] Drawerの4項目をResourceから表示できる
- [ ] クリックイベントを呼び出し側へ通知できる
