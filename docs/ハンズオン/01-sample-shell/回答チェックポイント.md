# 回答チェックポイント

回答コードはこのTemplateへ直接置かず、`solution/01-sample-shell`ブランチで管理する。
各Commitは、その時点でビルド可能な状態にする。

```text
solution/01-sample-shell
  01: add sample routes and placeholder screens
  02: add sample graph and app nav host registration
  03: add sample navigation components
  04: connect bottom navigation
  05: connect navigation drawer
  06: integrate common layout into sample routes
  07: fix back stack and complete review
```

学習者は課題ブランチから作業を開始し、各Step終了後に対応する回答Commitと比較する。

必要であれば、次のタグを回答ブランチへ付ける。

```text
solution-01-sample-shell-01
solution-01-sample-shell-02
solution-01-sample-shell-03
solution-01-sample-shell-04
solution-01-sample-shell-05
solution-01-sample-shell-06
solution-01-sample-shell-07
```

## 回答Commitの確認観点

| Commit | 到達点 |
|---|---|
| 01 | Route定義とPlaceholder画面だけが存在する |
| 02 | SampleGraphとAppNavHostが接続される |
| 03 | 共通TopAppBar / Drawer / Bottom Navigationが表示できる |
| 04 | Sampleの3画面をBottom Navigationで切り替えられる |
| 05 | DrawerからLegal / License / VersionInfoへ遷移できる |
| 06 | 各Sample Routeへ共通レイアウトが統合される |
| 07 | Back Stack、Preview、Build、Starter整理、自己レビューが完了する |
