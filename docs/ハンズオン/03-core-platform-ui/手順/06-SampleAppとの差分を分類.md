# 手順06 SampleAppとの差分を分類

TemplateとSampleAppを比較し、差分ごとに次を記録する。

```text
差分ファイル:
差分の内容:
03で理解する内容か:
後続Stepで実装するStep:
後続で実装する理由:
```

## 分類の観点

- Core Platform / UIの共通契約
- AppRootとThemeの接続
- DataStore、Database、Network
- Feature固有の文言やState
- Legal / License / VersionInfo固有のUI

SampleAppにあるものを見つけても、すぐに03へ追加しない。対応表の責務と後続Stepを確認して分類する。
