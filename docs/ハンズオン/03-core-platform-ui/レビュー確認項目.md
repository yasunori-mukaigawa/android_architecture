# HANDS-003 レビュー確認項目

## Module / DI

- [ ] `core:platform`と`core:ui`の責務を説明できる
- [ ] Android依存をCore Platformへ閉じ込める理由を説明できる
- [ ] interface、Android実装、DI登録、利用側の関係を追跡できる
- [ ] Feature固有の業務処理をCoreへ追加していない

## Provider

- [ ] StringProviderの利用経路を説明できる
- [ ] DateTimeProviderとAppClockの役割を説明できる
- [ ] DispatcherProviderの差し替え意図を説明できる
- [ ] CoroutineScopeProviderの必要性を説明できる
- [ ] ViewModelやUseCaseへContextを直接渡していない

## Logging / Navigation

- [ ] AppLoggerとTimber実装の分離を説明できる
- [ ] Application起動時のLogger初期化箇所を確認した
- [ ] RouteArgumentEncoderが薄い補助であることを説明できる
- [ ] CoreがNavControllerやNavHostを保持していないことを確認した
- [ ] ExternalUriOpenerの責務を説明できる

## UI / Theme

- [ ] AppDialogが表示部品に留まっていることを確認した
- [ ] LoadingContentが状態判断を自動化していないことを確認した
- [ ] BaseAppThemeからMaterialThemeが適用される流れを説明できる
- [ ] BaseThemeRegistryがThemePresetを解決する責務を説明できる
- [ ] Themeの一時変更を確認し、元へ戻した

## SampleApp比較

- [ ] SampleAppに存在する差分を確認した
- [ ] 03で扱う差分と後続Stepで扱う差分を分類した
- [ ] SampleAppとの差分を独自判断で残していない
- [ ] 実験用コードや不要な抽象化を残していない
